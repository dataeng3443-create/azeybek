⚡ 4. DAX MEASURE OPTİMİZASYONU
================================================================================

📊 Mevcut Measure Sayısı: 2
⚠️  Çok az measure bulunmuş. Gelişmiş analytics için yeterli değil.

💡 ÖNERILEN OPTİMİZE MEASURE'LAR:

📌 Toplam_Şikayet
   Formula:
DEFINE MEASURE veri[Toplam_Şikayet] = 
    COUNTA(veri[SikayetID])
RETURN [Toplam_Şikayet]
   Durum: ✅ Simple COUNTA - Hızlı
   Sorun: ❌ Henüz yok

📌 Şikayet_Dönem_Başına
   Formula:
DEFINE MEASURE veri[Şikayet_Dönem_Başına] = 
    CALCULATE(
        COUNTA(veri[SikayetID]),
        ALL(Tarih),
        Tarih[Year] = MAX(Tarih[Year]),
        Tarih[MonthNo] = MAX(Tarih[MonthNo])
    )
RETURN [Şikayet_Dönem_Başına]
   Durum: ✅ CALCULATE optimized
   Sorun: ⚠️  Kümülatif hesaplar yavaş olabilir

📌 Memnuniyet_Oranı
   Formula:
DEFINE MEASURE veri[Memnuniyet_Oranı] =
    VAR Memnun = CALCULATE(COUNTA(veri[SikayetID]), veri[MemnuniyetDerecesi]="Memnun")
    VAR Toplam = COUNTA(veri[SikayetID])
RETURN DIVIDE(Memnun, Toplam, 0)
RETURN [Memnuniyet_Oranı]
   Durum: ✅ VAR kullanarak caching
   Sorun: ⚠️  DIVIDE(by_zero_handling)

📌 Şikayet_Artış_Trendi
   Formula:
DEFINE MEASURE veri[Şikayet_Artış_Trendi] =
    VAR Geçen_Dönem = CALCULATE(
        COUNTA(veri[SikayetID]),
        DATEADD(Tarih[Date], -1, MONTH)
    )
    VAR Bu_Dönem = COUNTA(veri[SikayetID])
RETURN DIVIDE(Bu_Dönem - Geçen_Dönem, Geçen_Dönem, 0)
RETURN [Şikayet_Artış_Trendi]
   Durum: ✅ DATEADD pattern - efficient
   Sorun: ⚠️  İlk dönem NULL dönebilir

📌 Kategori_Dağılımı
   Formula:
DEFINE MEASURE veri[Kategori_Dağılımı] =
    COUNTIF(veri[SikayetKonu], veri[SikayetKonu])
RETURN [Kategori_Dağılımı]
   Durum: ⚠️  COUNTIF yerine GROUPBY kullan
   Sorun: ❌ Performans sorunu var


⚡ GENEL DAX PERFORMANS TAVSİYELERİ:

   1. KULLAN: 
      ✅ CALCULATE()  → Context modifikasyonu
      ✅ VAR          → Tekrar hesaplamayı önle
      ✅ DATEADD()    → Dönem karşılaştırma
   
   2. KAÇIN:
      ❌ SUMPRODUCT()  → Yavaş
      ❌ FILTER()      → Çok fırsat
      ❌ Nested CALCULATE → Karmaşık
   
   3. BENCH MARKS:
      ✅ Simple Measure:    < 10ms
      ⚠️  Complex Measure:   < 100ms
      ❌ Slow Measure:      > 500ms
   
   4. TESTING:
      DAX Studio kullan:
      • Server Timings göster
      • Query Cache kontrol et
      • Storage Engine vs Formula Engine karşılaştır
